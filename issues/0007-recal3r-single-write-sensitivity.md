# [Experiment] ReCal3Rの一回のscene-state書き込みは，次の3D予測精度をどの程度変えるか

> 状態：結果あり．4系列・8介入の継続判定は0 / 4で不合格となり，予定していた大規模実験は実行しなかった．

## 背景と仮説

[ReCal3R](https://arxiv.org/abs/2607.05356)は，時間順に並んだ画像を一枚ずつ処理する．各画像について現在の形状をまず予測し，その後，新しく得た情報を，過去の画像から蓄積して後続画像でも参照する潜在的な場面表現へ選択的に混ぜる．以下では，この潜在的な場面表現を`scene state`と呼ぶ．

一回の画像から`scene state`へ書き込まれた情報が因果的に使われているなら，その書き込みだけを止めると，次に処理する画像の奥行きまたは3D点の予測誤差が変わるはずである．一方，直後の予測がすでに過去の情報で十分なら，系列平均の変化は小さい可能性がある．また，平均が小さくても，新しい3D証拠を多く含む時点だけに効果が集中する可能性は残る．

本Issueでは，同じ画像履歴を二条件へ分岐し，一枚の現在出力を計算した後の`scene state`書き込みだけを通常どおり行うか，無効にするかを変えた．姿勢メモリと既知の補助状態は共通に保ち，次の等間隔抽出画像を，その画像自身がメモリへ書き込む前に評価した．

![一回のscene-state書き込みだけを変える介入設計](https://github.com/KohsukeIde/e2e-3d-notes/blob/main/figures/recal3r_write_intervention_design.png?raw=1)

*図1．1〜10枚目までの履歴，11枚目の入力と現在出力，姿勢メモリ，既知の補助状態を共通にし，11枚目の現在出力を計算した後の`scene state`書き込みだけを変える．12枚目は，12枚目自身がメモリへ書き込む前に評価する．同じ設計を21枚目から22枚目にも適用した．*

## 実験設定

| 項目 | 設定 |
|---|---|
| モデル | 公式ReCal3Rコード |
| 学習済み重み | 公式CUT3Rの512解像度用最終重み |
| データセット | TUM RGB-D Freiburg3 walkingの`static`，`xyz`，`rpy`，`halfsphere` |
| 入力 | 各系列から時間順を保って決定的・等間隔に抽出した32枚 |
| 事前に決めた介入 | `11枚目→12枚目`と`21枚目→22枚目` |
| 比較で変えるもの | 書き込み対象画像の現在出力を計算した後の`scene state`書き込みだけ |
| 固定するもの | 同じ画像履歴，書き込み対象画像，現在出力，姿勢メモリ，既知の補助状態 |
| 評価時点 | 次の等間隔抽出画像がメモリへ書き込む前 |
| 時間差 | 0.772〜1.214秒 |
| 奥行きの位置合わせ | 両介入より前にある共通の2〜9枚目だけで一つのaffine変換を合わせ，両条件へ再利用 |
| 3D点の位置合わせ | 両介入より前にある共通の2〜9枚目だけで一つのsimilarity変換を合わせ，両条件へ再利用 |
| 有効画素 | 正解奥行きで定義し，両条件で共通 |
| 評価指標 | 奥行きAbsRel，位置合わせ後の3D点誤差 |
| 独立単位 | 4系列．8介入を8個の独立系列とは数えない |
| 学習・調整 | 学習，追加学習，最適化，後処理なし |
| カメラ | 継続判定の評価指標ではないため，本Issueの介入時点別結果から除外 |

## 結果を見る前に固定した継続判定

各系列について，まず二つの介入の誤差を条件ごとに平均する．次に，通常の書き込み条件に対する書き込み停止条件の絶対相対変化を，奥行きと3D点で別々に計算する．同一条件を繰り返したときの最大数値変動を`sham floor`と呼び，各評価指標の基準を`max(1%，10 × sham floor)`とした．奥行きまたは3D点のどちらかが基準を超えた系列を通過とし，4系列中3系列以上が通過した場合だけ，書き込み配分を比較する大規模実験へ進むと決めた．

全評価指標の`sham floor`は0だったため，実際の基準は1%だった．この1%は，計算資源を用いる後続実験へ進むかを決める予備実験の継続基準である．統計的有意性の検定，実用上の同等性を示す許容幅，または効果がないことを示す境界ではない．介入時点ごとの事後観察によって，この系列単位の判定方法は変更しない．

## 結果

### Q1．比較は本当に一回のscene-state書き込みだけを変えているか

**A．既知の状態については，一回の`scene state`書き込みだけが異なる比較になっていた．**

両条件で，書き込み対象画像の現在出力，姿勢メモリ，既知の補助状態，正解で定義した有効画素が一致することを検査した．初回と再実行を合わせた16件の検証記録はすべて有効で，全検査を通過し，無効な介入と無効出力はいずれも0だった．意図的に誤った時点の状態を使う検証用比較では差を検出できたため，評価器が変化を全く検出できないわけではない．

同じ処理系で再実行すると，継続判定に使う全数値と定性的な全配列要素が完全に一致した．これは計算再現性であり，独立実装や別標本による外部再現ではない．また，補助状態の監査は既知の状態を列挙した一覧に基づくため，あらゆる未知の可変状態が存在しないことまでは証明しない．

### Q2．一回の書き込みを止めると，次の3D予測精度は平均してどの程度変わるか

**A．系列内で二つの誤差を先に平均した絶対相対変化は，奥行きと3D点の両方で4系列すべて1%未満だった．**

| 系列 | 奥行きAbsRel | 位置合わせ後の3D点誤差 | 判定 |
|---|---:|---:|---|
| static | 0.0441% | 0.0950% | 不合格 |
| xyz | 0.7556% | 0.5662% | 不合格 |
| rpy | 0.3460% | 0.3047% | 不合格 |
| halfsphere | 0.3819% | 0.3054% | 不合格 |

![系列平均の一回書き込み効果](https://github.com/KohsukeIde/e2e-3d-notes/blob/main/figures/recal3r_write_recording_effect.png?raw=1)

*図2．各棒は，一つの系列内で二つの誤差を条件ごとに平均してから求めた絶対相対変化である．低いほど条件差が小さい．赤破線は事前に固定した1%の継続基準であり，奥行きと位置合わせ後の3D点の全8値がこれを下回った．*

通過は0 / 4であり，3 / 4を要求した継続判定は不合格となった．したがって，`scene state`と姿勢メモリを交差させる介入，同じ書き込み量を一様に配る条件，完全な書き込み条件，後続8画像の集約は実行しなかった．これらは未評価であり，差がなかったという結果ではない．

### Q3．平均が小さいなら，すべての時点で書き込みが不要だったのか

**A．不要だったとは言えず，介入時点ごとの効果は異なった．**

符号付き効果は`（書き込み停止時の誤差 − 通常時の誤差）／通常時の誤差 × 100`である．正なら通常の書き込みが次画像の誤差を減らし，負なら書き込みを止めた方が誤差を減らしたことを表す．

![8介入時点の符号付き効果](https://github.com/KohsukeIde/e2e-3d-notes/blob/main/figures/recal3r_write_event_effect.png?raw=1)

*図3．左は奥行きAbsRel，右は位置合わせ後の3D点誤差であり，各横棒は事前に決めた一つの介入を表す．0線より右では通常の書き込みが誤差を減らし，左では書き込み停止が誤差を減らした．線で介入時点を結ばず，各時点の対応比較として表示した．*

`xyz`の`11枚目→12枚目`では，通常の書き込みによる誤差減少が奥行き+2.6651%，3D点+2.1960%だった．同じ系列の`21枚目→22枚目`では，奥行き−0.0560%，3D点−0.0205%だった．この不均一性は，特定時点の3D証拠が他の時点より高い影響を持つ可能性と整合するが，自然な可視範囲，重なり，カメラ運動が揃っていないため原因は特定できない．また，この事後観察は凍結した系列判定を変更しない．

### Q4．画像上ではどこが変わったか

**A．奥行き誤差の変化は画像全体で一様ではなく，増加と減少が局所的に混在した．**

![一回の書き込みを止めたときの画素別奥行き変化](https://github.com/KohsukeIde/e2e-3d-notes/blob/main/figures/recal3r_write_qualitative.png?raw=1)

*図4．8介入時点のうち奥行きの正の効果が最大だった`walking xyz`の`11枚目→12枚目`を事後的に選んだ．上段は次のRGB画像，正解奥行き，通常条件と書き込み停止条件の位置合わせ後の奥行きであり，三つの奥行き図は共通範囲で表示する．下段左二つは共通範囲の画素別AbsRel，中央右は「書き込み停止 − 通常」のAbsRel差である．赤は書き込み停止で誤差が増え，青は誤差が減った画素，灰色は正解上の無効画素を表す．この一例は局所的な変化を示す事後的な図示であり，独立な検証例ではない．*

全有効画素の平均は局所的な変化を希釈し得る．この図から，どの種類の表面，新規性，遮蔽，再訪要求が効果を生んだかは決められない．

## この結果から言えること

この4つの32枚へ間引いた画像系列と8介入では，一回の`scene state`書き込みが次の抽出画像へ与えた系列平均の奥行き・位置合わせ後3D点誤差の変化は，事前に決めた1%の継続基準未満だった．一方で，影響の大きさは時点間で一様ではなかった．

これは，ReCal3Rのメモリが使われていないこと，長期の蓄積効果が小さいこと，書き込みが不要であること，内部表現の配分方式が劣ること，カメラ推定の変化が1%未満であること，または原論文が反証されたことを意味しない．

## 限界

- 同じデータセットに属する4系列・8介入だけの記述的な予備実験であり，一般化や有意差を主張できない．
- 正解上で有効な全画素の平均は，局所的な効果を希釈し得る．
- 一回の書き込みと，0.772〜1.214秒後にある次の抽出画像だけを評価した．累積効果，長期保持，再訪時の効果は分からない．
- 介入時点間で自然な可視範囲，画像の重なり，カメラ運動を統制していない．
- 一つの学習済み重みと同じ計算経路だけを用いた．
- カメラは継続判定の評価指標ではない．
- 定性的な例は事後的に選んだ．
- 完全な書き込み配分実験と姿勢メモリ介入は実行していない．
- 既知の状態を列挙した一覧は，あらゆる可変状態が存在しないことを証明しない．

## 次の問い

次に調べるべき問いは，3D証拠の新規性，遮蔽，将来の再訪要求を制御することで，高い影響を持つ観測を構成または予測できるかである．

## 事実と解釈の区分

| 区分 | このIssueでの内容 |
|---|---|
| 原論文 | ReCal3Rが順序付き画像を処理し，新しい情報を後続画像へ持ち越す潜在表現へ選択的に書き込む構成 |
| 手元の実験 | 4系列・8介入の対応比較，系列集計，0 / 4の継続判定，介入時点間の効果差 |
| 同じ処理系での再実行 | 継続判定に使う全数値と定性的な全配列要素が一致したこと |
